The beginner guide covers user-facing workflows and administration. The operations guide covers installation, runtime prerequisites, deployment, service configuration, maintenance, API access, and development. Runtime-specific tool inventories remain owned by the runtime; the Portal documentation does not promise that every installed runtime offers identical tools.
