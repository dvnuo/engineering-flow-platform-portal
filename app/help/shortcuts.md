## Shortcuts

| Keys | What it does |
| --- | --- |
| `{mod} + K` | Focus the message box |
| `/` | Focus the message box |
| `{mod} + Shift + O` | Start a new chat |
| `Enter` | Send |
| `Shift + Enter` | New line |
| `Esc` | Stop the current run, or close the open dialog |
