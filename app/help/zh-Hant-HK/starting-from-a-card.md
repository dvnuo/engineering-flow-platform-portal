## 會列出你的工作的卡片

新聊天開啟時會顯示幾張卡片。需要你提供資訊的卡片（工單、pull request、分支）會開啟一個清單，列出你自己最近的內容：你檢視過或指派給你的問題、等你審閱的 pull request、你推送過但還未有 pull request 的分支。按一下其中一行，助手就會開始工作。在輸入框中輸入可以篩選清單或搜尋。

輸入框一直可用。和以前一樣，貼上連結或輸入編號後按 Enter 即可；清單只是一條捷徑。

有些卡片需要不止一項資訊，例如一個 story 和要執行的平台。填好各個欄位後按**繼續**。

卡片上可能帶有一個小的計數，例如**2 個待審閱**或**1 個失敗**：這是正在等你處理的工作，來自這張卡片開啟時顯示的同一個清單。

## 清單從哪裏來

Portal 使用你自己的連接器設定讀取清單，也就是你的助手所用的那些設定。關閉的連接器不會列出任何內容：卡片會告訴你需要在[連接器](#/help/concepts)中設定哪一個，輸入框仍然可用。

如果某個連接器跟隨管理員的預設設定，而預設設定使用共用帳戶登入，清單會按你的用戶名稱產生，並且不提供**最近檢視的**：那份瀏覽記錄屬於共用帳戶。

你選擇的內容只會以編號或連結的形式傳送。標題和摘要只顯示給你看，不會傳送給助手。

## 助手工作區中的分支

建立 pull request 時，清單最前面是這個助手的工作區中已簽出、並且有自己的提交或變更的分支：也就是助手完成、但工作區之外還不知道的工作。

## 輸入時引用內容

在訊息輸入框中輸入 `#`，可以在自己寫訊息時使用同樣的清單：最近的 Jira 問題、pull request 和 Confluence 頁面。用方向鍵和 Enter 插入其中一項，或者繼續輸入以忽略清單。Enter 仍然會傳送你的訊息。

## 以前用過的值

每張卡片會在這個瀏覽器中記住你最近給它的幾個值，並顯示在**以前用過的**下面。
