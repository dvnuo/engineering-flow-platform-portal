## 用途

讀取工單、發表留言和建立問題。助手以你的身份操作，所以它寫下的任何內容都會顯示你的名字。

它只能看到你自己的帳戶看得到的專案。

## 正確填寫權杖

用戶名稱是你的 Atlassian 帳戶電郵，不是顯示名稱。

權杖是你在 Atlassian 帳戶中建立的 API 權杖，不是你的密碼。Atlassian 不接受以密碼存取 API。

網站 URL 和 API 版本已由管理員填好。

## 無法正常運作時

Atlassian 權杖可能會被撤銷或過期。如果任務因憑證錯誤而失敗，通常就是這個原因。

如果出現的是權限錯誤，則表示權杖沒有問題，而是你的帳戶無法存取那個專案——請聯絡專案管理員。
