## Copilot 現在怎樣計費

由 2026 年 6 月起，GitHub Copilot 按 **token** 計費，以 GitHub AI Credits 結算（1 額度 = $0.01）。Business 計劃每位成員每月包含 $19，在機構層面合併計算；超出之後按相同的 token 單價計費。以往「每則訊息算一次高級請求」的模式已經取消。

一次模型呼叫的費用 = 輸入 token × 單價 + 快取輸入 token × 折扣單價 + 輸出 token（包括推理）× 單價。GPT-6.1 Sol 預設級別的價格：輸入每百萬 token $2，快取輸入 $0.10，輸出 $10。

## 為什麼一則訊息可能花掉上百額度

- 回答一則訊息往往需要十多步甚至更多：讀取檔案、執行指令、查看結果。**每一步都會重新傳送整個上下文**（系統提示、工具定義、歷史記錄、工具輸出）。
- 15 步、每步上下文 100K token，就是 150 萬輸入 token：快取命中時約 100 額度，未命中時達 400 額度或更多。
- 推理（「思考」）按輸出計費，單價是輸入的五倍。思考深度設為「高」會增加大量推理 token。

將滑鼠移到回答右上角的模型徽章上（顯示類似「Auto → GPT-6 Luna」），就可以在模型資訊下方看到這個回答的費用：步數、輸入 / 輸出 token、快取命中率、估算額度和計費級別。估算依據 GitHub 公佈的價目表，並非實際帳單。

## 272K 這條線

單次請求的輸入超過 **272K token** 時，GPT-6 系列會轉為長上下文級別，**所有價格加倍**。「上下文」面板會在用量條上標示這條線；超過之後，用量條會變成警告色，面板會顯示「長上下文」。

在「上下文大小」的預設選項中，1M 標示為「長上下文 2×」。選擇之前，請先弄清楚這代表什麼。

## 怎樣少花一些

1. **新話題開新對話**。上下文越長，每則訊息越貴，而且舊對話中的工具輸出會一直留在上下文裏。
2. **少貼上大檔案**。貼上的內容每一步都會重新傳送；讓助手只讀取它需要的部分會更便宜。
3. **思考深度保持「中」**。這對日常工作已經足夠；任務確實需要時，才在「執行設定」中為該對話調至「高」。
4. **模型保持 Auto**。Copilot 會為簡單的請求選用較便宜的模型，並減免 10% 費用。
5. **留意「暫停」提示**。一則訊息超出額度上限或步數上限時，助手會停下來並說明原因；只有你想讓它繼續時，才按「繼續」。

## 查看餘額

- 「上下文」面板中的「本月 Copilot 餘額」會顯示已用 / 剩餘額度和重設日期（數據來自 GitHub 的配額端點，不保證一定可用）。
- 助手詳情中的「用量（30 天）」會顯示過去 30 天的請求數、token 數和估算額度。
- 權威數字以 GitHub 的 Billing 頁面為準：[GitHub Copilot 的模型與定價](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing)。
