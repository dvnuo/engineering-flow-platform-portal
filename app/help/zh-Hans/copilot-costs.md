## Copilot 现在怎样计费

自 2026 年 6 月起，GitHub Copilot 按 **token** 计费，以 GitHub AI Credits 结算（1 额度 = $0.01）。Business 计划每位成员每月包含 $19，在组织层面合并计算；超出之后按相同的 token 单价计费。过去「每条消息算一次高级请求」的模式已经取消。

一次模型调用的费用 = 输入 token × 单价 + 缓存输入 token × 折扣单价 + 输出 token（含推理）× 单价。GPT-6.1 Sol 默认档位的价格：输入每百万 token $2，缓存输入 $0.10，输出 $10。

## 为什么一条消息可能花掉上百额度

- 回答一条消息常常需要十几步甚至更多：读取文件、运行命令、查看结果。**每一步都会重新发送整个上下文**（系统提示词、工具定义、历史记录、工具输出）。
- 15 步、每步上下文 100K token，就是 150 万输入 token：缓存命中时约 100 额度，未命中时 400 额度甚至更多。
- 推理（「思考」）按输出计费，单价是输入的五倍。思考深度设为「高」会多出大量推理 token。

把鼠标悬停在回答右上角的模型徽章上（显示类似「Auto → GPT-6 Luna」），就能在模型信息下方看到这条回答的费用：步数、输入 / 输出 token、缓存命中率、估算额度和计费档位。估算基于 GitHub 公布的价目表，并不是实际账单。

## 272K 这条线

单次请求的输入超过 **272K token** 时，GPT-6 系列会进入长上下文档位，**所有价格翻倍**。「上下文」面板会在用量条上标出这条线；超过之后，用量条会变成警告色，面板上会显示「长上下文」。

在「上下文大小」的预设中，1M 标为「长上下文 2×」。选择它之前，请先弄清楚这意味着什么。

## 怎样少花一些

1. **新话题开新会话**。上下文越长，每条消息越贵，而且旧会话中的工具输出会一直留在上下文里。
2. **少粘贴大文件**。粘贴的内容每一步都会重新发送；让助手只读取它需要的部分更省钱。
3. **思考深度保持「中」**。这对日常工作已经足够；任务确实需要时，再在「运行设置」里为该会话调到「高」。
4. **模型保持 Auto**。Copilot 会为简单的请求选用更便宜的模型，并减免 10% 的费用。
5. **留意「暂停」提示**。一条消息超出额度上限或步数上限时，助手会停下来并说明原因；只有你想让它继续时，才点击「继续」。

## 查看余额

- 「上下文」面板中的「本月 Copilot 余额」显示已用 / 剩余额度和重置日期（数据来自 GitHub 的配额接口，该接口不保证始终可用）。
- 助手详情中的「用量（30 天）」显示最近 30 天的请求数、token 数和估算额度。
- 权威数字以 GitHub 的 Billing 页面为准：[GitHub Copilot 的模型与定价](https://docs.github.com/en/copilot/reference/copilot-billing/models-and-pricing)。
