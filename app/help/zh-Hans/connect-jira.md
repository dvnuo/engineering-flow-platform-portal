## 用途

读取工单、发表评论和创建问题。助手以你的身份操作，所以它写下的任何内容都会显示你的名字。

它只能看到你自己的账号能看到的项目。

## 正确填写令牌

用户名是你的 Atlassian 账号邮箱，不是显示名称。

令牌是你在 Atlassian 账号中创建的 API 令牌，不是你的密码。Atlassian 不接受用密码访问 API。

站点 URL 和 API 版本已由管理员填好。

## 无法正常工作时

Atlassian 令牌可能被撤销或过期。任务因凭证错误而失败，通常就是这个原因。

如果是权限错误，则说明令牌没有问题，而是你的账号无法访问那个项目——请联系项目管理员。
