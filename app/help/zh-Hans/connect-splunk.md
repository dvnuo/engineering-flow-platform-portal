## 用途

在助手排查问题时搜索你的日志：某个服务最近一小时的错误、某个请求 ID 在各个组件中的记录、某件事发生的频率。它通过 `splunk` CLI 执行搜索，而且总是带上时间范围和结果数量限制，所以即使查询写得不严谨，也不会拉取整个索引。

它只读取搜索结果；不会创建告警、保存的搜索或仪表板，也从不写入索引。

## 填写什么

- **URL** 是管理 API 的地址，不是网页地址：端口通常是 `8089`，例如 `https://splunk-api.example.com:8089`。
- **认证令牌**在 Splunk 的 Settings → Tokens 中创建。如果你的 Splunk 不签发令牌，可以改用用户名和密码。
- **默认索引**是查询未指定索引时搜索的索引，例如 `app_prod`。**默认起始时间**是请求未给出时间范围时使用的范围，采用 Splunk 的相对时间写法，如 `-1h` 或 `-24h`。**最大结果数**限制一次搜索最多返回多少个事件（1 到 10000）。
- **名称**是助手用 `--instance` 指定这个实例时使用的名字。
- **应用**是你希望助手看到的保存的搜索、宏和查找表（lookup）所属的 Splunk 应用。只有当这些对象是全局对象时才留空。它就是你在 Splunk 中浏览这些对象时 URL 里的名称，例如 `/en-US/app/search/` 中的 `search`。不填的话，助手只会在全局命名空间中查找，然后报告什么也没找到。**所有者**与应用配合使用，通常留空，表示该角色能看到的任何所有者。

## 无法正常工作时

管理端口出现证书错误很常见：这个端口经常使用自签名证书。请向 Splunk 管理员询问哪个地址出示的是受信任的证书。搜索没有返回任何结果，通常是时间范围太窄或索引不对；助手会随结果一并报告这两项。
