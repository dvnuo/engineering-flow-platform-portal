## What this is for

Reading pages for context and publishing results back as pages.

Anything published shows you as the author, with a footer noting it was
generated by an assistant.

## Getting the token right

Which token you need depends on where your Confluence runs.

On Atlassian Cloud (the address ends in atlassian.net), Confluence and Jira
share Atlassian API tokens. If you already created one for Jira, paste the
same value here. The username is again your Atlassian account email.

On a Confluence your company hosts (Data Center), create a personal access
token from your profile settings in Confluence. It needs no username, and a
token made in Jira does not work here.
