App packages

Builds you upload go straight to BrowserStack and are kept there for 30 days. Recordings and test runs pick a build here; give every build of the same app the same custom id and scripts that name the custom id always get the newest one.

A Jenkins or Nexus URL is downloaded with the credentials in your Jenkins or Nexus connector. Any other https URL is handed to BrowserStack, which downloads it from the internet.

Recording test steps

Open a chat with your assistant and choose Recording in the tool bar. The assistant starts a BrowserStack device with the build you pick and holds it while you record short segments (log in, skip the introduction, choose a currency) in Appium Inspector.

    {% if appium_inspector_available %}
  • Portal hosts Appium Inspector: the Recording panel opens it already attached to the device. Nothing to install.
  • If you prefer the desktop app, the panel also shows the session details to attach it by hand.
    • {% else %}
  • Install Appium Inspector 2026.5.1 or later (Windows or macOS). Older versions cannot attach to a BrowserStack session by id.
  • The Recording panel shows the session id and hub to attach to; record in the Inspector, then upload the code it generates in the panel.
    • {% endif %}
  • Type real values while recording; password fields are never stored, and the assistant turns the other values into parameters for your test data.
