Default connections

The connection shape every new member's profile starts from — instance URLs, API versions, project and space keys. Members then supply only their own credentials.

Credentials are rejected here. This seed is shared with every member, so it must never carry a token, password, API key, or access key. A save containing one is refused rather than stored.
